💡 상품 썸네일 뷰어 사용법

1. 데이터 준비 및 적용

두 가지 방법 중 편한 방법을 선택하세요. (http:// 또는 https:// 형식 모두 인식합니다.)

  • CSV 파일: 엑셀에서 .csv 형식으로 저장한 파일을 첨부합니다.
  • 텍스트 붙여넣기: 엑셀 셀을 여러 개 드래그 복사한 뒤 빈칸에 바로 붙여넣습니다.

2. ⌨️ 기본 단축키 안내

  • Q 또는 ← : 이전 이미지
  • E 또는 → : 다음 이미지
  • 1, 2, 3 : 정방형 크기 프리셋 적용

3. 🔍 상세페이지 확대/축소 (Zoom & Pan)

  • Ctrl + 마우스 휠 : 이미지 확대/축소
  • 마우스 드래그 : 확대된 상태에서 위치 이동
  • 일반 마우스 휠 : 확대된 상태에서 위/아래 이동
  • 더블 클릭 : 확대 비율 및 위치 초기화
