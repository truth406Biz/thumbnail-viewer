💡 상품 썸네일 뷰어 사용법

1. 데이터 준비 및 적용

두 가지 방법 중 편한 방법을 선택하세요.

  • CSV 파일: 엑셀에서 .csv 형식으로 저장한 파일을 첨부합니다.
  • 텍스트 붙여넣기: 엑셀 셀을 여러 개 복사한 뒤 빈칸에 바로 붙여넣습니다. (URL이 붙어있어도 자동 분리!)

2. ⌨️ 단축키 안내

  • Q 또는 ← : 이전 이미지
  • E 또는 → : 다음 이미지
  • 1, 2, 3 : 정방형 크기 프리셋 적용
  • A : 세로 길이 자동맞춤 모드 켜기/끄기

3. 🔍 조작 기능 가이드

  • 모서리 조절: 썸네일 상자의 모서리를 드래그하면 중앙을 기준으로 안정적으로 크기가 조절됩니다.
  • 세로 길이 자동맞춤(A): 이미지 원본 비율에 맞게 상자가 길어집니다. 마우스 휠로 편하게 스크롤하세요.
  • 부분 확대(Ctrl + 휠): 특정 부분을 확대해서 볼 수 있으며, 드래그로 이동이 가능합니다. (더블클릭 시 원상복구)
